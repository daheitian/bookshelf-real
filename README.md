# 书架 · 真实书房的静态快照

我的微信读书书架，导成静态页面挂在 GitHub Pages 上。打开就是一整面书墙，可以翻、可以按评分排序、可以点开看笔记。

**在线地址**：https://daheitian.github.io/bookshelf-real/

## 里面有什么

- 502 本书、16 个分类，按微信读书的分类归档
- 封面图（微信读书 CDN 原图压到 300px 宽，共约 9 MB）
- 阅读进度、推荐值、评分人数
- 352 本书的笔记：8960 条划线、271 条想法、69 篇书评

## 怎么用

- 拖拽转视角，滚轮缩放
- 右下角切换 `Spines / Covers`（书脊 / 封面）
- 「按评分」在分类内按推荐值降序，自动切到封面视图
- 点任意一本书，翻开看详情和笔记
- 按 `L` 关灯

## 它是怎么生成的

不是手写的。源头是本地跑的 Node 服务（`bookshelf-site`），它代理微信读书 API 并缓存书架数据，
再用两个脚本导出成这里的静态文件：

```bash
# 1. 导出书架 + 笔记（--notes 才会拉笔记全文，约 1–2 分钟）
node tools/export-real.mjs --notes

# 2. 压缩封面（71 MB 原图 → 9 MB）
python tools/pack-covers.py
```

生成的文件：

| 文件 | 内容 |
| --- | --- |
| `js/real-data.js` | 书架数据（`window.__REAL`），封面指向 `covers/` 相对路径 |
| `js/real-notes.js` | 笔记全文（`window.__REAL_NOTES`） |
| `js/real-shim.js` | 适配层，把 `/api/*` 请求接到上面两个数据文件 |

`js/app.js`、`js/scene.js`、`js/atlas.js` 来自正式版，几乎没改 —— 只把 `coverSrc()`
改成遇到相对路径直接返回，这样静态站不需要服务端代理封面图。

## 说明

- 数据是**导出那一刻的快照**，不会自动更新。想刷新就重跑上面两条命令再 push。
- 页面里没有任何 Key 或凭据，只有书架本身。要接自己的书架得跑那个 Node 服务。
- 封面图版权归微信读书与各出版社，这里只作个人书架展示用。
