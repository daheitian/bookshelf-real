把这间书房换成你自己的

书架上的每一本、每一道划线都来自微信读书。填上你自己的 API Key，这里就会长成你的书房 —— 和别人的完全不重叠。

Key 从哪来？

微信读书的 Agent 接口 Key，形如 wrk- 开头的一长串。它就是你在本机 .env 里配的那一串；填进来之后只存在这台浏览器（localStorage）和这台服务器 data/u/<你的 uid>/ 目录里，不会写到日志，也不会传给第三方。

换设备、换浏览器要重填一次；点「清除」随时可以把自己那间收掉。
